Sheets Manager

Connect your Google Sheet in 3 quick steps — no API keys needed.

1
Create your Google Sheet
Open Google Sheets and make a new sheet. In row 1 add headers: Name  Date  Remark
2
Publish the sheet to the web
File → Share → Publish to web
Choose Sheet1 + Comma-separated values (.csv) → click Publish.
3
Deploy a Google Apps Script web app
In your sheet: Extensions → Apps Script → paste the script below → Save → Deploy as Web App (Anyone can access) → copy the URL.
